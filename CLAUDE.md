# CLAUDE.md

Project-specific guidance for Claude Code.

## Project Overview

Single-file Python script (`Stash_Sqlite_Renamer.py`) that renames video files on disk by reading metadata from a [Stash](https://github.com/stashapp/stash) SQLite database.

## Key Configuration (top of script)

| Variable | Default | Purpose |
|---|---|---|
| `DB_PATH` | hardcoded path | Path to the Stash `.sqlite` database |
| `DRY_RUN` | `False` | If `True`, no files or DB are modified |
| `USING_LOG` | `True` | Write a `rename_log.txt` for rollback reference |
| `FEMALE_ONLY` | `False` | Restrict performer names to female gender only |
| `DEBUG_MODE` | `True` | Print verbose debug output |

## Filename Template Variables

`$date`, `$performer`, `$title`, `$studio`, `$height`

## Important Files

- `Stash_Sqlite_Renamer.py` — main script
- `requirements.txt` — only dependency: `progressbar2` (installs as the `progressbar` module)
- `rename_log.txt` — generated; logs `scene_id|old_path|new_path`
- `renamer_dryrun.txt` — generated by `DRY_RUN=True`
- `renamer_duplicate.txt` — generated when duplicate filenames are detected
- `renamer_fail.txt` — generated when OS rename fails
- `stash-go.sqlite` — gitignored; the live Stash database (never commit)

## Cautions

- The script directly modifies files on disk and updates the SQLite DB.
- Always set `DRY_RUN = True` and review `renamer_dryrun.txt` before a real run.
- The "personal configuration" section (lines 309–333) contains the user's tag-to-template mappings and path filters. Treat it as user data: when editing it, confirm the user's intended tag names and templates rather than inferring from the rest of the script.

## Testing
